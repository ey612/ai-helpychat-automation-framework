# AI HelpyChat 자동화 QA 프로젝트

부트캠프 1차 프로젝트 - AI 채팅봇 자동화 테스트
- 프로젝트 기간: 2025.12 ~ 2025.12
- 리팩토링 기간: 2025.01 ~ 2025.01

📌 프로젝트 개요
### 배경
부트캠프 1차 프로젝트로, AI 채팅봇 서비스(AI HelpyChat)의 자동화 테스트를 진행했습니다.

### 문제 상황

- ⚠️ 프로젝트 종료 시점: 각 팀원이 로컬 환경에서 개별 작업
- ⚠️ 코드 미통합: 5명의 코드가 분산되어 있는 상태
- ⚠️ 구조 불일치: 각자 다른 방식으로 코드 작성

### 해결 과정
프로젝트 종료 후 POM(Page Object Model) 패턴을 적용하여 전체 코드를 재구성하고 통합했습니다.
